# SRT Editor User Guide

このガイドは、SRT Editor の説明書botが参照する一次情報です。アプリの実装に合わせて、利用者向けの操作・制約・トラブル対応を網羅します。

## 概要

SRT Editor は、動画とSRT字幕ファイルをブラウザ内で読み込み、動画・波形・字幕リストを連動させながら字幕を校正するWebアプリです。

主な用途:

- SRT字幕のテキスト修正
- セグメント単位の開始・終了時刻調整
- 動画位置と字幕位置の相互ジャンプ
- 波形を見ながら字幕タイミングを調整
- 読み速度や重複などの品質チェック
- SRTの再書き出し
- 縦書き台本PDFの生成

ファイル処理は基本的にブラウザ内で完結します。動画・SRTは通常サーバーへアップロードされません。説明書botでGeminiを使う場合、質問文とこのガイド本文だけがAPIへ送信され、読み込んだ動画・SRT本文は送信しません。

## ファイル読み込み

### 動画を読み込む

上部ツールバーの「動画」ボタンから動画ファイルを選択します。読み込んだ動画は左側の動画プレイヤーに表示されます。

動画を読み込むとできること:

- 再生・停止
- 現在時刻に合わせた字幕セグメント検出
- 波形表示
- 無音検出
- 現在時刻をセグメントの開始・終了に反映

### SRTを読み込む

上部ツールバーの「SRT」ボタンからSRTファイルを選択します。読み込むと右側にセグメント一覧が表示されます。

対応する文字コード:

- UTF-8 with BOM (`utf-8-sig`)
- UTF-8
- CP932
- Shift_JIS

読み込んだSRTの文字コードは、SRT出力時にも保持されます。

### 前回セッションの復帰

SRTを読み込んだとき、同じファイル名の前回編集セッションがIndexedDBに残っている場合、復帰確認が表示されます。

- 「復帰する」: 前回保存された編集状態を読み込みます。
- 「破棄して新規」: 前回セッションを削除し、今回読み込んだSRTを使います。

自動保存はSRT名とセグメント内容を対象にします。動画ファイル本体は保存しません。

ツールバーの「途中復帰」ボタンでも保存済みの途中編集を明示的に復帰できます。SRTを開いている場合はそのSRT名の保存データを優先し、SRTを開いていない場合は最新の保存データを復帰します。

## 画面構成

### 上部ツールバー

主なボタン:

- 動画: 動画ファイルを読み込む
- SRT: SRTファイルを読み込む
- Undo: 直前の編集を戻す
- Redo: 戻した編集をやり直す
- 途中保存: 現在の編集状態をIndexedDBへ即時保存
- 途中復帰: 保存済みの途中編集を復帰
- 検索: 検索・置換パネルを開く
- タイムシフト: タイムコード一括調整
- 無音検出: 字幕が無い発話らしい区間を検出
- QC: 品質チェックパネルの表示切替
- 追従ON/OFF: 再生位置に合わせた自動スクロール切替
- 設定: QC設定を開く
- ?: ヘルプ・説明書botを開く
- SRT出力: 編集済みSRTをダウンロード
- PDF化: 縦書き台本PDFを生成

### 左ペイン

左ペインには動画プレイヤー、波形、操作ヒントが表示されます。

### 右ペイン

右ペインには字幕セグメント一覧が表示されます。各セグメントで時刻、話者、セリフ、CPS、QC警告、行操作を編集できます。

### QCパネル

QCボタンで右側に品質チェックパネルを表示します。CPS超過、重複、ギャップ不足、表示時間不足、禁則などの問題を一覧し、クリックで該当セグメントへジャンプできます。

## 動画操作

### 再生・停止

動画プレイヤー上で通常の動画操作ができます。テキスト入力欄の外では `Space` キーでも再生・停止できます。

### 前後移動

テキスト入力欄の外で:

- `J`: 2秒戻る
- `L`: 2秒進む

### セグメント移動

テキスト入力欄の外で:

- `[`: 前のセグメントへ移動
- `]`: 次のセグメントへ移動

選択中セグメントがあればそれを基準にし、無ければ再生中セグメントを基準にします。

## 波形操作

波形は読み込んだ動画の音声から生成されます。

### シーク

波形の上部グレーバーはシーク専用です。クリックまたはドラッグで動画の再生位置を移動できます。

### セグメント表示

字幕セグメントは波形上のリージョンとして表示されます。

- 青: 再生中のセグメント
- 橙: 選択中のセグメント

### タイミング調整

セグメント端をドラッグすると、そのセグメントの開始・終了時刻を調整できます。

### ズーム

波形上で `Ctrl + ホイール` を使うと波形をズームできます。

### 無音検出結果

無音検出を実行すると、字幕が無い発話らしい区間が波形上に表示されます。該当リージョンをクリックすると、その区間に新規セグメントを挿入できます。

## セグメント編集

### セグメント選択

セグメント行をクリックまたはフォーカスすると選択中になります。選択中のセグメントは橙色で表示されます。

### 動画位置へジャンプ

行左側の再生ボタンを押すと、そのセグメントの開始時刻へ動画がジャンプします。

### 開始・終了時刻の直接編集

各セグメントには開始時刻と終了時刻の入力欄があります。SRT形式のタイムコードを直接編集できます。

### 時刻の微調整

開始時刻:

- `-.1`: 0.1秒戻す
- `-1`: 1秒戻す
- `+.1`: 0.1秒進める
- `+1`: 1秒進める

終了時刻:

- `-.1`: 0.1秒戻す
- `+.1`: 0.1秒進める
- `+1`: 1秒進める

### 現在の動画位置を開始・終了に設定

選択中セグメントに対して:

- `I`: 現在の動画位置を開始時刻に設定
- `O`: 現在の動画位置を終了時刻に設定

行内の `I` / `O` ボタンでも同じ操作ができます。

### セリフ編集

セリフ欄で字幕本文を編集します。話者がある場合は、話者入力欄とセリフ欄のペアで管理されます。

### 話者追加・削除

「＋話者」ボタンで同じセグメント内に話者行を追加できます。話者行右側の削除ボタンで話者行を削除できます。最後の1行は削除できません。

### セリフ内部の改行

セリフ欄にカーソルを置いた状態で:

- `Alt + Enter`: カーソル位置に改行を挿入
- 「改行」ボタン: カーソル位置に改行を挿入

`Ctrl + Enter` はセグメント分割に使うため、内部改行には使いません。

### セグメント分割

セリフ欄の分割したい位置にカーソルを置いて `Ctrl + Enter` を押すと、セグメントが2つに分割されます。

分割時刻:

- 現在の動画位置がそのセグメント範囲内なら、現在の動画位置
- 範囲外なら、セグメントの中央

### セグメント結合

「結合」ボタンを押すと、現在のセグメントと次のセグメントを結合します。本文は改行でつながり、終了時刻は次のセグメントの終了時刻になります。

### セグメント複製

「複製」ボタンを押すと、現在のセグメントを直後にコピーします。本文と話者情報はコピーされます。時間は元セグメントの直後に配置され、次セグメントがある場合は重なりにくい範囲へ調整されます。

### セグメント順の入れ替え

「↑」「↓」ボタンでセグメントの表示順を上下に入れ替えます。時間は自動再計算しません。台本上の順序だけ調整したいときに使います。

### セグメント削除

「削除」ボタンでセグメントを削除します。

### 行間への新規挿入

セグメントとセグメントの間に表示される `+` バーをクリックすると、その位置に空の新規セグメントを挿入します。

### 現在位置に新規挿入

テキスト入力欄の外で `N` を押すと、現在の動画位置に新規セグメントを挿入します。長さは初期値として約1.5秒です。

## Undo / Redo

対応操作:

- テキスト編集
- タイムコード変更
- 挿入
- 削除
- 分割
- 結合
- 複製
- 順序入れ替え
- タイムシフト
- 検索置換
- 話者タグ正規化

ショートカット:

- `Ctrl + Z`: Undo
- `Ctrl + Y`: Redo
- `Ctrl + Shift + Z`: Redo

## 検索・置換

`Ctrl + F` またはツールバーの「検索」から検索・置換パネルを開きます。

機能:

- 検索語の入力
- 置換語の入力
- 正規表現の利用
- 大文字小文字の区別
- 全置換
- 置換プレビュー

### 話者タグ正規化

検索・置換パネルから、話者タグ表記を一括統一できます。

- 全角: `（名前）`
- 半角: `(名前)`

行頭の話者タグが対象です。

## タイムシフト

ツールバーのタイムシフトボタンから、タイムコードを一括でずらせます。

対象:

- 全セグメント
- 選択中セグメント以降

入力値はミリ秒単位です。正の値で後ろへ、負の値で前へ移動します。0未満になる時刻は0に丸められます。

## QC機能

QCは字幕の品質問題をリアルタイムに検出します。

検出項目:

- CPS超過
- セグメントの重複
- セグメント間ギャップ不足
- 最短表示時間不足
- 行頭禁則

### CPS

CPSはCharacters Per Second、1秒あたりの文字数です。読み速度の目安です。

色:

- 緑: 読みやすい範囲
- 黄: 注意
- オレンジ: 警告
- 赤: 閾値超過

デフォルト閾値は17 CPSです。設定から変更できます。

### 話者タグをCPSから除外

設定で「CPS計算で話者タグを除外」をONにすると、`（名前）` や `(名前)` を文字数計算から除外します。

### 最短表示時間・ギャップ・禁則

最短表示時間のデフォルトは700msです。隣接セグメント間の最小ギャップのデフォルトは84msです。行頭禁則チェックは設定でON/OFFできます。

## 無音検出

動画とSRTを読み込んだ状態で「無音検出」を押すと、音声解析により字幕が無い発話らしい区間を検出します。

使い方:

1. 動画を読み込む
2. SRTを読み込む
3. 「無音検出」を押す
4. 波形上の検出区間を確認する
5. 必要な区間をクリックして新規セグメントを挿入する

注意:

- 音声解析はブラウザ内で行います。
- BGMやノイズが多い動画では誤検出があります。
- 「字幕が無い発話らしい区間」を補助的に探す機能です。

## SRT出力

「SRT出力」ボタンで編集済みSRTをダウンロードします。

仕様:

- 読み込んだSRTの文字コードを保持します。
- セグメント番号は出力時に並び順に合わせて再採番されます。
- セグメント本文の改行はSRT内に保持されます。

## PDF化

「PDF化」ボタンで縦書き台本PDFを生成します。

仕様:

- ブラウザ内でPDFを生成します。
- 日本語フォントとして `Noto Serif JP` を使用します。
- SRTの話者タグを解釈して台本形式に整形します。
- セリフ内部の手動改行は、PDFレイアウト内でも明示的な改行として反映されます。
- 長い文章は紙面に収まるように分割されます。

## 設定

ツールバーの歯車ボタンからQC設定を開きます。

変更できる項目:

- CPS閾値
- 話者タグをCPS計算から除外するか
- 最短表示時間
- セグメント間の最小ギャップ
- 行頭禁則チェックのON/OFF

設定はブラウザのlocalStorageに保存されます。

## 自動保存

編集内容はIndexedDBに自動保存されます。

保存対象:

- SRTファイル名
- 文字コード
- セグメント一覧
- 保存時刻

保存対象外:

- 動画ファイル本体
- 動画の再生位置

ブラウザのストレージを削除すると、自動保存データも消えます。

### 手動の途中保存・復帰

ツールバーの「途中保存」を押すと、現在の編集状態を即時保存します。自動保存の800ms待ちを待たずに、保存済み状態を明示できます。

ツールバーの「途中復帰」を押すと、保存済みの途中編集を読み込みます。

- SRTを開いている場合: 現在のSRTファイル名に対応する保存データを復帰します。
- SRTを開いていない場合: IndexedDB内の最新保存データを復帰します。
- 復帰データが無い場合: 画面上部の保存ステータスに「復帰データなし」と表示します。

## エラー時の対応

### 画面が壊れた・白くなった

ErrorBoundaryが表示された場合:

- 「画面を再描画」: 軽微な表示エラーから復帰
- 「ページリロード」: アプリを再読み込み
- 「保存データを削除してリロード」: IndexedDB等の破損が疑われる場合の最終手段

### SRTが文字化けする

対応文字コードはUTF-8、UTF-8 BOM、CP932、Shift_JISです。特殊な文字コードのファイルは事前に変換してください。

### 無音検出が不正確

BGM、ノイズ、極端に小さい声、効果音が多い動画では誤検出があります。検出結果は補助情報として扱ってください。

### PDF化に時間がかかる

長いSRTや大量セグメントではPDF生成に時間がかかります。生成中は「PDF生成中」と表示されます。

## 説明書bot

ヘルプ画面には説明書botがあります。

動作:

- Gemini APIが利用できる場合、このガイドを参照して回答します。
- Gemini APIが使えない場合、ローカル固定FAQにフォールバックします。
- 動画ファイルやSRT本文はGeminiに送信しません。

回答範囲:

- このアプリの使い方
- ショートカット
- セグメント編集
- QC
- 無音検出
- SRT出力
- PDF化
- トラブル対応

回答できない内容:

- 読み込んだ動画やSRT本文の内容分析
- 外部サービスの仕様
- アプリに存在しない機能の実行
